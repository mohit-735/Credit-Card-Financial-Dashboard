# Credit-Card-Financial-Dashboard
# 💳 Credit Card Financial Dashboard | Power BI & SQL Server

## 📌 Project Overview

The **Credit Card Financial Dashboard** is an interactive data analytics project built using **Power BI and SQL Server**. The project focuses on analyzing credit card transactions, customer behavior, revenue, interest, and overall financial performance.

The dashboard provides meaningful business insights through interactive visualizations, KPI cards, filters, and customer segmentation.

This project demonstrates a complete data analytics workflow, from raw CSV data storage in SQL Server to data visualization and reporting in Power BI.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze credit card transaction data.
- Monitor overall revenue and financial performance.
- Track total transaction amount and transaction count.
- Analyze interest earned from customers.
- Identify revenue trends over time.
- Compare different credit card categories.
- Analyze customer spending behavior.
- Understand customer demographics and segmentation.
- Build an interactive and insightful Power BI dashboard.

---

## 🛠️ Tools & Technologies Used

- **Power BI** – Data visualization and dashboard development

🗄️ SQL Server Integration

The project uses SQL Server as the database layer.

Raw CSV files are imported into SQL Server tables, and Power BI is connected to the SQL Server database for reporting and analysis.

CSV Files → SQL Server → Power BI Dashboard

This architecture allows Power BI to retrieve the latest available data from SQL Server whenever the dataset is refreshed.
